# roblox-admin-panel
Многофункциональный парсер команд (Админ-панель)Стек: Luau (Roblox Studio)Проект представляет собой админ-панель, ориентированную на текстовые команды (Cmd). В основе лежит парсер команд, реализованный через связку клиентского (LocalScript) и серверного (Script) скриптов.Функционал и кастомизация:Базовые команды: Реализованы speed, jump, kill, heal, kick.Продвинутый таргетинг: Поддерживаются аргументы и выбор цели, например: speed [num] [PlayerName].Расширяемость: Структура позволяет легко дописывать собственные условия для новых команд.Безопасность и архитектура (Anti-Exploit & Best Practices):Доступ к панели определяется по таблице User ID администраторов. Реализована строгая двухуровневая защита:Изоляция интерфейса (ServerStorage): Сам AdminGui хранится на сервере в ServerStorage. При входе игрока сервер проверяет его ID, и только авторизованным администраторам клонирует GUI в PlayerGui. Обычные игроки и читеры вообще не имеют доступа к файлу интерфейса.Клиентская проверка: На стороне клиента LocalScript делает первичную проверку для удобства интерфейса.Серверная валидация (100% Server-Side Protection): Финальная жесткая проверка User ID происходит на сервере при каждом вызове команды. Если читер попытается сымитировать отправку команды напрямую, сервер отклонит запрос, так как сверяет ID со своей таблицей.
